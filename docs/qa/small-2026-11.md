# ui-avatar, ui-skeleton, ui-separator QA (November 2026)

Screenshots: `docs/qa/small/`, three skins by light and dark by 360, 768
and 1280 px. Checked by `apps/playground/e2e/small.spec.ts` in all six
skin and mode combinations, plus the shared axe and unit tests.

| Check | Result |
|-------|--------|
| Avatar is a square circle; three sizes ordered sm < md < lg | passes |
| An image fills the circle | passes |
| Initials >= 4.5:1 on solid and soft fills | passes except the upstream values below |
| Separator is 1px, horizontal and vertical | passes |
| Skeleton is visible; the pulse stops under reduced motion | passes (unit test) |
| axe, six combinations | passes (allow-list entries below) |

## Contrast exceptions (palette values, mirrored from upstream)

| Skin / mode | Avatar | Ratio |
|-------------|--------|-------|
| shadcn light | solid `ui-danger` | 3.60 |
| daisyUI light | `ui-soft ui-danger` | 4.47 |
| daisyUI dark | solid and soft `ui-primary` | 4.13, 4.18 |

The spec asserts this exact set; axe has one entry per case. Same values
as `a11y-2026-11.md`.

## Notes

- The shadcn dark separator is faint because shadcn's `--border` is faint;
  a decorative rule is exempt from the 3:1 non-text rule.
- The accessible name of an avatar and the `aria-hidden` / `aria-busy`
  pairing for skeletons are the consumer's and are documented.
