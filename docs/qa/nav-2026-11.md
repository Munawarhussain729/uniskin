# ui-breadcrumb and ui-pagination QA (November 2026)

Screenshots: `docs/qa/nav/`, three skins by light and dark by 360, 768 and
1280 px. Checked by `apps/playground/e2e/nav.spec.ts` in all six skin and
mode combinations, plus the shared axe and unit tests.

| Check | Result |
|-------|--------|
| Breadcrumb separators appear between items only, as empty-alt generated content | passes |
| The current breadcrumb item is bold | passes |
| Breadcrumb sizes are ordered | passes |
| Pagination: the current page is filled and the others are not; `ui-active` matches `aria-current` | passes |
| Pagination items are at least 24px tall (WCAG 2.5.8) | passes |
| A disabled item ignores the pointer | passes |
| Current-page label >= 4.5:1 | passes except the upstream values below |
| axe, six combinations | passes (allow-list entries below) |

## Findings

- **Icon-only Prev and Next** with an `aria-label` that differs from the
  visible glyph fail axe `label-content-name-mismatch`, and `aria-disabled`
  on a link without `href` fails `aria-prohibited-attr`. The documented
  markup uses visible text and a disabled `<button>`.
